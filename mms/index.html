Kebijakan Privasi MMS NOC

Bahasa Indonesia · English below

Terakhir diperbarui: 16 Oktober 2026 (versi 1.2.0: rilis pertama MMS NOC). Berlaku untuk semua versi aplikasi MMS NOC.

1. Tentang aplikasi dan penerbit

MMS NOC ("aplikasi") diterbitkan oleh PT. Megarap Mitra Solusi ("MMS", "kami") untuk staf dan mitra kerjanya. Aplikasi adalah klien untuk server Netra milik PT. Megarap Mitra Solusi — platform NOC (Network Operation Center) yang dipasang dan dikelola PT. Megarap Mitra Solusi sendiri — dan hanya terhubung ke server itu; alamatnya tetap di aplikasi dan tidak bisa diganti pengguna. Aplikasi dibangun dari perangkat lunak klien Netra Mobile yang dikembangkan Tri Adi Santoso ("pengembang aplikasi").

2. Ringkasan

  • Tanpa iklan dan tanpa ID iklan. Aplikasi tidak memuat SDK analitik, pelacakan, maupun pelaporan crash; satu-satunya pengecualian adalah data diagnostik yang dikumpulkan Google Maps SDK untuk Google saat Peta Fiber memakai Google Maps (§4.3).
  • Data Netra (akun, perangkat jaringan, alert, dan lainnya) hanya dipertukarkan antara ponsel ini dan server Netra PT. Megarap Mitra Solusi, selalu lewat koneksi terenkripsi (HTTPS).
  • Layanan pihak lain hanya dipakai untuk fungsi tertentu: Google Firebase Cloud Messaging (notifikasi) dan Google Maps atau OpenStreetMap (peta dasar).
  • Password tidak pernah disimpan — password login maupun password CLI terminal. Data sidik jari dan wajah tidak pernah diakses aplikasi.

4. Data yang dikirim dan tujuannya

4.1 Server Netra PT. Megarap Mitra Solusi

  • Saat memeriksa server: permintaan informasi branding dan versi server (tanpa data pribadi).
  • Saat masuk: username atau email dan password (hanya untuk diverifikasi server, tidak disimpan aplikasi), jenis platform (Android/iOS), nama model perangkat (mis. "Samsung SM-F966B"), dan versi aplikasi.
  • Saat membuka terminal dari internet (versi 1.2.0 dan sesudahnya): password CLI yang diberikan admin Netra (server Netra 1.26.0). Password CLI hanya diketik untuk membuka terminal dari internet, hanya dikirim ke server Netra Anda untuk diverifikasi, dan tidak pernah disimpan aplikasi — sama seperti password login.
  • Selama sesi: permintaan data yang Anda buka dan tindakan yang Anda lakukan — misalnya acknowledge alert beserta catatan opsional, kata pencarian dan filter, target alat jaringan (ping, traceroute, DNS, cek port — dijalankan oleh server), dan ketikan di terminal SSH/Telnet yang diteruskan server ke perangkat jaringan.
  • Untuk notifikasi: token pendaftaran Firebase Cloud Messaging (FCM), platform, nama model perangkat, dan versi aplikasi.
  • Di latar belakang (versi 1.1.0 dan sesudahnya): agar Anda tidak perlu sering masuk ulang, aplikasi memperpanjang sesi sekitar setiap 6 jam (Android WorkManager; di iOS lewat Background App Refresh bila diizinkan iOS) dan saat server mengirim pemberitahuan bahwa sesi akan berakhir. Perpanjangan hanya mengirim token sesi ke server Netra PT. Megarap Mitra Solusi — tidak ada data baru yang dikumpulkan, dan tidak ada yang dikirim ke pihak lain. Bila Anda menekan "Bukan saya — cabut" pada notifikasi login baru, aplikasi meminta daftar sesi akun Anda dari server lalu mencabut sesi itu.

Data di server dikelola PT. Megarap Mitra Solusi sesuai kebijakan internal perusahaan (mis. log audit).

4.2 Google Firebase Cloud Messaging (notifikasi push)

Setelah Anda masuk, aplikasi meminta token pendaftaran dari Firebase Cloud Messaging (layanan Google) dan mendaftarkannya ke server Netra PT. Megarap Mitra Solusi. Server Netra mengirim notifikasi alert — judul dan ringkasan alert (misalnya nama perangkat dan jenis gangguan) serta ID alert/perangkat — lewat FCM ke ponsel Anda, memakai proyek Firebase yang dikelola pengembang aplikasi atas nama PT. Megarap Mitra Solusi. Server Netra 1.25.0 juga mengirim pemberitahuan sesi (sesi akan atau sudah berakhir) dan keamanan (login baru ke akun Anda: nama dan platform perangkat, alamat IP, waktu, dan ID sesi). Dalam proses ini Google memproses token, ID instalasi Firebase, isi notifikasi selama pengantaran, dan metrik pengantaran sebagai penyedia layanan. Pengembang aplikasi tidak menyimpan isi notifikasi; konsol Firebase hanya menampilkan statistik pengantaran agregat. Token diganti (dihapus lalu dibuat baru) setiap kali Anda keluar atau sesi berakhir. Kebijakan privasi Google: https://policies.google.com/privacy

4.3 Peta dasar Peta Fiber

  • Google Maps (bila tersedia di build dan perangkat; hanya saat Peta Fiber dibuka): Maps SDK mengirim ke Google area peta yang dilihat, alamat IP, metadata permintaan (model perangkat, versi OS dan SDK), pengenal pseudonim khusus Maps SDK, data crash di dalam kode SDK, dan interaksi peta (geser, zoom) — untuk memuat peta serta untuk memelihara dan meningkatkan layanan Google. Berlaku kebijakan privasi Google.
  • OpenStreetMap (bila Google Maps tidak tersedia): ubin peta diminta langsung dari server OpenStreetMap Foundation; permintaan memuat alamat IP, identitas aplikasi (NetraMobile/<versi> (android)), dan koordinat ubin yang dilihat. Kebijakan privasi OSMF: https://osmfoundation.org/wiki/Privacy_Policy
  • Data kabel dan titik Netra tidak dikirim ke Google maupun OSMF — hanya ubin latar yang dimuat.
  • Aplikasi tidak memakai lokasi GPS dan tidak meminta izin lokasi.

4.4 Tidak ada pihak lain

Tidak ada data yang dijual, dipakai untuk iklan, atau dikirim ke pengembang aplikasi.

5. Izin aplikasi (Android)

  • Internet — menghubungi server Netra, FCM, dan peta.
  • Notifikasi (Android 13+) — menampilkan notifikasi alert; boleh ditolak, aplikasi tetap berfungsi.
  • Biometrik — kunci aplikasi opsional dengan sidik jari atau kunci layar.
  • Izin pendukung: menerima pesan FCM, menjaga perangkat tetap aktif sebentar saat memproses notifikasi atau memperpanjang sesi, getar, status jaringan, dan menjadwalkan ulang perpanjangan sesi setelah perangkat dinyalakan ulang.
  • Tidak ada layanan latar depan (foreground service). Tidak ada izin lokasi, kamera, mikrofon, kontak, maupun berkas.

6. Biometrik

Kunci aplikasi (opsional) memakai verifikasi sistem operasi (BiometricPrompt di Android, Face ID/Touch ID di iOS). Aplikasi hanya menerima hasil berhasil atau gagal; sidik jari dan data wajah tidak pernah diakses, tidak disimpan aplikasi, dan tidak meninggalkan perangkat.

7. Keamanan

  • Koneksi wajib terenkripsi (HTTPS/WSS); lalu lintas tanpa enkripsi diblokir.
  • Sertifikat self-signed hanya dipakai setelah Anda mengonfirmasi sidik jari SHA-256-nya, lalu dipin per server; perubahan sertifikat diblokir sampai Anda menyetujuinya lagi.
  • Token sesi disimpan di penyimpanan aman sistem; password login dan password CLI tidak disimpan.

8. Penyimpanan dan penghapusan data

  • Keluar (Pengaturan → Keluar): perangkat dihapus dari daftar notifikasi server, sesi diakhiri di server, token FCM dihapus, lalu token sesi dan salinan data offline dihapus dari perangkat.
  • Sesi di perangkat lain: Pengaturan → Sesi saya → Cabut, atau "Bukan saya — cabut" pada notifikasi login baru.
  • Hapus semuanya: hapus aplikasi, atau Setelan Android → Aplikasi → MMS NOC → Penyimpanan → Hapus data.
  • Data di server Netra (akun, riwayat sesi, log audit, perangkat notifikasi terdaftar) dikendalikan PT. Megarap Mitra Solusi. Untuk melihat, mengubah, atau menghapus akun dan datanya, hubungi administrator Netra PT. Megarap Mitra Solusi.

9. Anak-anak

Aplikasi ditujukan untuk staf jaringan/NOC dewasa dan tidak ditujukan untuk anak-anak.

10. Perubahan kebijakan

Perubahan diumumkan di halaman ini dengan tanggal pembaruan baru; perubahan penting juga disebut di catatan rilis aplikasi.

11. Kontak

Pertanyaan tentang kebijakan ini: tri@mms.net.id (PT. Megarap Mitra Solusi). Untuk data di server Netra, hubungi administrator Netra PT. Megarap Mitra Solusi.

MMS NOC Privacy Policy

English · Bahasa Indonesia di atas

Last updated: 16 October 2026 (version 1.2.0: first MMS NOC release). Applies to all versions of the MMS NOC app.

1. About the app and the publisher

MMS NOC (the "app") is published by PT. Megarap Mitra Solusi ("MMS", "we") for its staff and partners. The app is a client for PT. Megarap Mitra Solusi's own Netra server — a NOC (Network Operation Center) platform that PT. Megarap Mitra Solusi installs and operates itself — and connects only to that server; its address is fixed in the app and cannot be changed by the user. The app is built from the Netra Mobile client software developed by Tri Adi Santoso (the "app developer").

2. Summary

  • No ads and no advertising ID. The app contains no analytics, tracking or crash-reporting SDK; the only exception is the diagnostic data the Google Maps SDK collects for Google when the fiber map uses Google Maps (§4.3).
  • Netra data (account, network devices, alerts and more) is exchanged only between this phone and PT. Megarap Mitra Solusi's Netra server, always over an encrypted connection (HTTPS).
  • Third-party services are used only for specific functions: Google Firebase Cloud Messaging (notifications) and Google Maps or OpenStreetMap (base map).
  • Passwords are never stored — neither the sign-in password nor the terminal CLI password. Fingerprint and face data are never accessed by the app.

4. Data sent and where it goes

4.1 PT. Megarap Mitra Solusi's Netra server

  • When checking the server: requests for the server's branding and version information (no personal data).
  • When signing in: username or email and password (only for the server to verify, never stored by the app), platform (Android/iOS), device model name (e.g. "Samsung SM-F966B") and app version.
  • When opening a terminal over the internet (version 1.2.0 and later): the CLI password issued by your Netra administrator (Netra server 1.26.0). The CLI password is typed only to open a terminal over the internet, is sent only to the Netra server for verification, and is never stored by the app — just like the sign-in password.
  • During a session: requests for the data you open and the actions you take — for example acknowledging an alert with an optional note, search and filter terms, network tool targets (ping, traceroute, DNS, port check — executed by the server), and keystrokes in the SSH/Telnet terminal, which the server relays to network devices.
  • For notifications: the Firebase Cloud Messaging (FCM) registration token, platform, device model name and app version.
  • In the background (version 1.1.0 and later): so that you do not have to sign in often, the app extends the session about every 6 hours (Android WorkManager; on iOS through Background App Refresh when iOS allows it) and when the server announces that the session is about to end. An extension only sends the session token to PT. Megarap Mitra Solusi's Netra server — no new data is collected and nothing is sent to anyone else. When you tap "Bukan saya — cabut" (Not me — revoke) on a new-login notification, the app requests your account's session list from the server and revokes that session.

Data on the server is managed by PT. Megarap Mitra Solusi under its internal policies (for example audit logs).

4.2 Google Firebase Cloud Messaging (push notifications)

After you sign in, the app requests a registration token from Firebase Cloud Messaging (a Google service) and registers it with PT. Megarap Mitra Solusi's Netra server. The Netra server sends alert notifications — the alert title and summary (for example a device name and the type of problem) plus alert/device IDs — through FCM to your phone, using a Firebase project managed by the app developer on behalf of PT. Megarap Mitra Solusi. Netra server 1.25.0 also sends session notices (session about to end or ended) and security notices (a new sign-in to your account: device name and platform, IP address, time, and session ID). In this process Google processes the token, the Firebase installation ID, the notification content while it is delivered, and delivery metrics as a service provider. The app developer does not store notification content; the Firebase console only shows aggregated delivery statistics. The token is replaced (deleted and recreated) whenever you sign out or your session ends. Google Privacy Policy: https://policies.google.com/privacy

4.3 Fiber map base map

  • Google Maps (when available in the build and on the device; only while the fiber map is open): the Maps SDK sends Google the viewed map area, the IP address, request metadata (device model, OS and SDK version), a pseudonymous Maps SDK identifier, crash data from within the SDK code, and map interactions (panning, zooming) — to load the map and to maintain and improve Google services. Google's privacy policy applies.
  • OpenStreetMap (when Google Maps is not available): map tiles are requested directly from OpenStreetMap Foundation servers; the requests include the IP address, the app identity (NetraMobile/<version> (android)) and the coordinates of the viewed tiles. OSMF Privacy Policy: https://osmfoundation.org/wiki/Privacy_Policy
  • Netra cable and point data is not sent to Google or the OSMF — only background tiles are loaded.
  • The app does not use GPS location and does not request location permission.

4.4 No one else

No data is sold, used for advertising, or sent to the app developer.

5. App permissions (Android)

  • Internet — to reach the Netra server, FCM and maps.
  • Notifications (Android 13+) — to show alert notifications; you may deny it and the app keeps working.
  • Biometrics — optional app lock with fingerprint or screen lock.
  • Support permissions: receive FCM messages, briefly keep the device awake while processing a notification or extending the session, vibrate, network state, and reschedule the session extension after the device restarts.
  • No foreground service. No location, camera, microphone, contacts or file permissions.

6. Biometrics

The optional app lock uses the operating system's verification (BiometricPrompt on Android, Face ID/Touch ID on iOS). The app only receives a success or failure result; fingerprint and face data are never accessed, never stored by the app, and never leave the device.

7. Security

  • Connections must be encrypted (HTTPS/WSS); unencrypted traffic is blocked.
  • A self-signed certificate is used only after you confirm its SHA-256 fingerprint, and it is then pinned per server; a changed certificate is blocked until you approve it again.
  • Session tokens are kept in the system's secure storage; sign-in and CLI passwords are not stored.

8. Retention and deletion

  • Sign out (Settings → Keluar): the device is removed from the server's notification list, the session is ended on the server, the FCM token is deleted, and the session token and offline data copy are deleted from the device.
  • Sessions on other devices: Settings → Sesi saya → Cabut, or "Bukan saya — cabut" on a new-login notification.
  • Delete everything: uninstall the app, or Android Settings → Apps → MMS NOC → Storage → Clear data.
  • Data on the Netra server (account, session history, audit logs, registered notification devices) is controlled by PT. Megarap Mitra Solusi. To access, correct or delete your account and its data, contact PT. Megarap Mitra Solusi's Netra administrator.

9. Children

The app is intended for adult network/NOC staff and is not directed at children.

10. Changes

Changes are published on this page with a new "last updated" date; significant changes are also mentioned in the app's release notes.

11. Contact

Questions about this policy: tri@mms.net.id (PT. Megarap Mitra Solusi). For data on the Netra server, contact PT. Megarap Mitra Solusi's Netra administrator.
