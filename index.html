Kebijakan Privasi Netra Mobile

Bahasa Indonesia · English below

Terakhir diperbarui: 7 Oktober 2026. Berlaku untuk aplikasi Netra Mobile versi 1.0.0 dan sesudahnya.

1. Tentang aplikasi dan penerbit

Netra Mobile ("aplikasi") diterbitkan oleh Tri Adi Santoso, pengembang perorangan ("pengembang", "kami"). Aplikasi adalah klien untuk server Netra — platform NOC (Network Operation Center) yang dipasang dan dikelola sendiri oleh ISP atau organisasi Anda ("operator server"). Pengembang tidak mengoperasikan server Netra Anda dan tidak menerima data Netra Anda.

2. Ringkasan

  • Tanpa iklan dan tanpa ID iklan. Aplikasi tidak memuat SDK analitik, pelacakan, maupun pelaporan crash; satu-satunya pengecualian adalah data diagnostik yang dikumpulkan Google Maps SDK untuk Google saat Peta Fiber memakai Google Maps (§4.3).
  • Data Netra (akun, perangkat jaringan, alert, dan lainnya) hanya dipertukarkan antara ponsel Anda dan server Netra yang alamatnya Anda masukkan sendiri, selalu lewat koneksi terenkripsi (HTTPS).
  • Pengembang tidak memiliki server yang menerima data Anda. Layanan pihak lain hanya dipakai untuk fungsi tertentu: Google Firebase Cloud Messaging (notifikasi) dan Google Maps atau OpenStreetMap (peta dasar).
  • Password tidak pernah disimpan. Data sidik jari dan wajah tidak pernah diakses aplikasi.

4. Data yang dikirim dan tujuannya

4.1 Server Netra yang Anda pilih (dioperasikan ISP/organisasi Anda)

  • Saat memeriksa server: permintaan informasi branding dan versi server (tanpa data pribadi).
  • Saat masuk: username atau email dan password (hanya untuk diverifikasi server, tidak disimpan aplikasi), jenis platform (Android/iOS), nama model perangkat (mis. "Samsung SM-F966B"), dan versi aplikasi.
  • Selama sesi: permintaan data yang Anda buka dan tindakan yang Anda lakukan — misalnya acknowledge alert beserta catatan opsional, kata pencarian dan filter, target alat jaringan (ping, traceroute, DNS, cek port — dijalankan oleh server), dan ketikan di terminal SSH/Telnet yang diteruskan server ke perangkat jaringan Anda.
  • Untuk notifikasi: token pendaftaran Firebase Cloud Messaging (FCM), platform, nama model perangkat, dan versi aplikasi.

Data di server dikelola operator server sesuai kebijakan organisasi Anda (misalnya log audit). Pengembang tidak punya akses ke server tersebut.

4.2 Google Firebase Cloud Messaging (notifikasi push)

Setelah Anda masuk, aplikasi meminta token pendaftaran dari Firebase Cloud Messaging (layanan Google) dan mendaftarkannya ke server Netra Anda. Server Netra mengirim notifikasi alert — judul dan ringkasan alert (misalnya nama perangkat dan jenis gangguan) serta ID alert/perangkat — lewat FCM ke ponsel Anda, memakai proyek Firebase milik pengembang. Dalam proses ini Google memproses token, ID instalasi Firebase, isi notifikasi selama pengantaran, dan metrik pengantaran sebagai penyedia layanan. Pengembang tidak menyimpan isi notifikasi; konsol Firebase hanya menampilkan statistik pengantaran agregat. Token diganti (dihapus lalu dibuat baru) setiap kali Anda keluar, berpindah server, atau sesi berakhir. Kebijakan privasi Google: https://policies.google.com/privacy

4.3 Peta dasar Peta Fiber

  • Google Maps (bila tersedia di build dan perangkat; hanya saat Peta Fiber dibuka): Maps SDK mengirim ke Google area peta yang dilihat, alamat IP, metadata permintaan (model perangkat, versi OS dan SDK), pengenal pseudonim khusus Maps SDK, data crash di dalam kode SDK, dan interaksi peta (geser, zoom) — untuk memuat peta serta untuk memelihara dan meningkatkan layanan Google. Berlaku kebijakan privasi Google.
  • OpenStreetMap (bila Google Maps tidak tersedia): ubin peta diminta langsung dari server OpenStreetMap Foundation; permintaan memuat alamat IP, identitas aplikasi (NetraMobile/<versi> (android)), dan koordinat ubin yang dilihat. Kebijakan privasi OSMF: https://osmfoundation.org/wiki/Privacy_Policy
  • Data kabel dan titik Netra tidak dikirim ke Google maupun OSMF — hanya ubin latar yang dimuat.
  • Aplikasi tidak memakai lokasi GPS dan tidak meminta izin lokasi.

4.4 Tidak ada pihak lain

Tidak ada data yang dijual, dipakai untuk iklan, atau dikirim ke pengembang.

5. Izin aplikasi (Android)

  • Internet — menghubungi server Netra, FCM, dan peta.
  • Notifikasi (Android 13+) — menampilkan notifikasi alert; boleh ditolak, aplikasi tetap berfungsi.
  • Biometrik — kunci aplikasi opsional dengan sidik jari atau kunci layar.
  • Izin pendukung notifikasi: menerima pesan FCM, menjaga perangkat tetap aktif sebentar saat memproses notifikasi, getar, dan status jaringan.
  • Tidak ada izin lokasi, kamera, mikrofon, kontak, maupun berkas.

6. Biometrik

Kunci aplikasi (opsional) memakai verifikasi sistem operasi (BiometricPrompt di Android, Face ID/Touch ID di iOS). Aplikasi hanya menerima hasil berhasil atau gagal; sidik jari dan data wajah tidak pernah diakses, tidak disimpan aplikasi, dan tidak meninggalkan perangkat.

7. Keamanan

  • Koneksi wajib terenkripsi (HTTPS/WSS); lalu lintas tanpa enkripsi diblokir.
  • Sertifikat self-signed hanya dipakai setelah Anda mengonfirmasi sidik jari SHA-256-nya, lalu dipin per server; perubahan sertifikat diblokir sampai Anda menyetujuinya lagi.
  • Token sesi disimpan di penyimpanan aman sistem; password tidak disimpan.

8. Penyimpanan dan penghapusan data

  • Keluar (Pengaturan → Keluar): perangkat dihapus dari daftar notifikasi server, sesi diakhiri di server, token FCM dihapus, lalu token sesi dan salinan data offline dihapus dari perangkat.
  • Hapus server (daftar Server → Opsi server → Hapus server): semua data profil itu dihapus dari perangkat, termasuk logo, salinan data, preferensi, dan sidik jari sertifikat.
  • Sesi di perangkat lain: Pengaturan → Sesi saya → Cabut.
  • Hapus semuanya: hapus aplikasi, atau Setelan Android → Aplikasi → Netra Mobile → Penyimpanan → Hapus data.
  • Data di server Netra (akun, riwayat sesi, log audit, perangkat notifikasi terdaftar) dikendalikan operator server. Untuk melihat, mengubah, atau menghapus akun dan datanya, hubungi administrator Netra di ISP/organisasi Anda. Pengembang tidak menyimpan data Anda, kecuali email yang Anda kirim sendiri kepada kami.

9. Anak-anak

Aplikasi ditujukan untuk staf jaringan/NOC dewasa dan tidak ditujukan untuk anak-anak.

10. Perubahan kebijakan

Perubahan diumumkan di halaman ini dengan tanggal pembaruan baru; perubahan penting juga disebut di catatan rilis aplikasi.

11. Kontak

Pertanyaan tentang kebijakan ini: aditardy@gmail.com. Untuk data di server Netra Anda, hubungi administrator Netra di ISP/organisasi Anda.

Netra Mobile Privacy Policy

English · Bahasa Indonesia di atas

Last updated: 7 October 2026. Applies to the Netra Mobile app version 1.0.0 and later.

1. About the app and the publisher

Netra Mobile (the "app") is published by Tri Adi Santoso, an individual developer ("developer", "we"). The app is a client for Netra servers — a NOC (Network Operation Center) platform that your ISP or organization installs and operates itself (the "server operator"). The developer does not operate your Netra server and does not receive your Netra data.

2. Summary

  • No ads and no advertising ID. The app contains no analytics, tracking or crash-reporting SDK; the only exception is the diagnostic data the Google Maps SDK collects for Google when the fiber map uses Google Maps (§4.3).
  • Netra data (account, network devices, alerts and more) is exchanged only between your phone and the Netra server whose address you enter yourself, always over an encrypted connection (HTTPS).
  • The developer has no server that receives your data. Third-party services are used only for specific functions: Google Firebase Cloud Messaging (notifications) and Google Maps or OpenStreetMap (base map).
  • Passwords are never stored. Fingerprint and face data are never accessed by the app.

App data is excluded from Android cloud backup and device transfer; on iOS the token is valid on this device only. The app does not write logs to files and does not send logs anywhere.

4. Data sent and where it goes

4.1 The Netra server you choose (operated by your ISP/organization)

  • When checking a server: requests for the server's branding and version information (no personal data).
  • When signing in: username or email and password (only for the server to verify, never stored by the app), platform (Android/iOS), device model name (e.g. "Samsung SM-F966B") and app version.
  • During a session: requests for the data you open and the actions you take — for example acknowledging an alert with an optional note, search and filter terms, network tool targets (ping, traceroute, DNS, port check — executed by the server), and keystrokes in the SSH/Telnet terminal, which the server relays to your network devices.
  • For notifications: the Firebase Cloud Messaging (FCM) registration token, platform, device model name and app version.

Data on the server is managed by the server operator under your organization's policies (for example audit logs). The developer has no access to that server.

4.2 Google Firebase Cloud Messaging (push notifications)

After you sign in, the app requests a registration token from Firebase Cloud Messaging (a Google service) and registers it with your Netra server. The Netra server sends alert notifications — the alert title and summary (for example a device name and the type of problem) plus alert/device IDs — through FCM to your phone, using the developer's Firebase project. In this process Google processes the token, the Firebase installation ID, the notification content while it is delivered, and delivery metrics as a service provider. The developer does not store notification content; the Firebase console only shows aggregated delivery statistics. The token is replaced (deleted and recreated) whenever you sign out, switch servers, or your session ends. Google Privacy Policy: https://policies.google.com/privacy

4.3 Fiber map base map

  • Google Maps (when available in the build and on the device; only while the fiber map is open): the Maps SDK sends Google the viewed map area, the IP address, request metadata (device model, OS and SDK version), a pseudonymous Maps SDK identifier, crash data from within the SDK code, and map interactions (panning, zooming) — to load the map and to maintain and improve Google services. Google's privacy policy applies.
  • OpenStreetMap (when Google Maps is not available): map tiles are requested directly from OpenStreetMap Foundation servers; the requests include the IP address, the app identity (NetraMobile/<version> (android)) and the coordinates of the viewed tiles. OSMF Privacy Policy: https://osmfoundation.org/wiki/Privacy_Policy
  • Netra cable and point data is not sent to Google or the OSMF — only background tiles are loaded.
  • The app does not use GPS location and does not request location permission.

4.4 No one else

No data is sold, used for advertising, or sent to the developer.

5. App permissions (Android)

  • Internet — to reach the Netra server, FCM and maps.
  • Notifications (Android 13+) — to show alert notifications; you may deny it and the app keeps working.
  • Biometrics — optional app lock with fingerprint or screen lock.
  • Notification support permissions: receive FCM messages, briefly keep the device awake while processing a notification, vibrate, and network state.
  • No location, camera, microphone, contacts or file permissions.

6. Biometrics

The optional app lock uses the operating system's verification (BiometricPrompt on Android, Face ID/Touch ID on iOS). The app only receives a success or failure result; fingerprint and face data are never accessed, never stored by the app, and never leave the device.

7. Security

  • Connections must be encrypted (HTTPS/WSS); unencrypted traffic is blocked.
  • A self-signed certificate is used only after you confirm its SHA-256 fingerprint, and it is then pinned per server; a changed certificate is blocked until you approve it again.
  • Session tokens are kept in the system's secure storage; passwords are not stored.

8. Retention and deletion

  • Sign out (Settings → Keluar): the device is removed from the server's notification list, the session is ended on the server, the FCM token is deleted, and the session token and offline data copy are deleted from the device.
  • Remove a server (Server list → Opsi server → Hapus server): all data of that profile is deleted from the device, including logo, data copy, preferences and certificate fingerprint.
  • Sessions on other devices: Settings → Sesi saya → Cabut.
  • Delete everything: uninstall the app, or Android Settings → Apps → Netra Mobile → Storage → Clear data.
  • Data on the Netra server (account, session history, audit logs, registered notification devices) is controlled by the server operator. To access, correct or delete your account and its data, contact the Netra administrator at your ISP/organization. The developer does not hold your data, except emails you send to us.

9. Children

The app is intended for adult network/NOC staff and is not directed at children.

10. Changes

Changes are published on this page with a new "last updated" date; significant changes are also mentioned in the app's release notes.

11. Contact

Questions about this policy: aditardy@gmail.com. For data on your Netra server, contact the Netra administrator at your ISP/organization.
